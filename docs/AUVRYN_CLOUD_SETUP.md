# AUVRYN Cloud — configuração gratuita

Para a versão 1.11.2, os recursos de conta e Study Circles usam Firebase Authentication + Cloud Firestore.

## Necessário
- Authentication: Google (e opcionalmente e-mail/senha).
- Firestore `(default)`.
- Regras de `firebase/firestore.rules` publicadas.

## Não necessário
- Cloud Storage.
- Plano Blaze.

Materiais do Study Circle são compartilhados por link (Drive, OneDrive, Dropbox, YouTube, artigos etc.). Arquivos pessoais locais continuam no dispositivo.
